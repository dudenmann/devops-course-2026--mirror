# Подготовка к КР

## 1. Когда rebase, когда merge?

Rebase — для личных веток, чтобы получить линейную историю.
Merge — для публичных веток, чтобы не ломать чужие копии.

## 2. Что будет, если сделать rebase публичной ветки?

Хеши изменятся, у коллег разойдётся история, push будет отклонён.
